# Чек-лист смены в предложении

Это отдельное локальное приложение Bitrix24. Оно не изменяет приложение
«Участники сделки» и не создаёт/не меняет карточки сделок.

## Установка

1. В Bitrix24 откройте **Приложения → Разработчикам → Локальное приложение**.
2. Создайте новое приложение типа **Сервер** с названием `Чек-лист смены`.
3. Выдайте права `crm`, `placement` и `lists`.
4. В поле обработчика установки укажите:

   ```
   https://<домен-приложения>/api/bitrix/shift-checklist/install
   ```

5. Сохраните и установите приложение. В карточке предложения появится новая
   вкладка **«Чек-лист смены»**.

## Как работает синхронизация

- Приложение читает поле предложения `UF_CRM_CARE_SHIFT_CHECKLIST`.
- Строки вида `✅ Название пункта` отмечаются в интерфейсе как выполненные.
- При сохранении выбранные пункты снова записываются в это же поле тем же
  форматом. Если снять все галочки, поле очищается.
- Произвольные пункты менеджер не создаёт. Каталог загружается из списка
  Bitrix24 **«Чек-лист сиделки»**: `IBLOCK_TYPE_ID=lists`, `IBLOCK_ID=28`.
  Сейчас в нём 40 пунктов. Добавление, переименование или удаление пункта в
  этом списке автоматически будет видно в приложении после обновления.
