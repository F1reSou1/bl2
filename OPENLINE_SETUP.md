# Чат сайта → Открытая линия Bitrix24

Этот проект реализует единый сценарий: пока бот знает ответ, он отвечает сам; при фразе «позвать менеджера» или при непонятном вопросе в Открытую линию передаётся вся история. Менеджер отвечает в Bitrix24, а клиент видит ответ в том же чате сайта.

Сделка при передаче диалога **не создаётся**. Через 10 минут без ответа посетителю предлагается оставить телефон; он уходит сообщением в эту же Открытую линию, а не создаёт сделку через `/api/leads`.

## Перед запуском

1. В Dokploy добавьте все переменные `BITRIX_OPENLINE_*`, `PUBLIC_SITE_URL` и `CHAT_*` из `.env.example`.
2. Сгенерируйте для `BITRIX_OPENLINE_CALLBACK_TOKEN` длинную случайную строку. Это не пароль сотрудника, но секрет обработчика Bitrix24 — не публикуйте его.
3. Добавьте постоянный volume Dokploy: `/app/data`. Он хранит токен локального приложения и активные диалоги. Без него после перезапуска сайта менеджерские ответы не смогут вернуться посетителю.
4. Задеплойте сайт по инструкции в `DOKPLOY.md`. Обработчики должны быть доступны снаружи по HTTPS.

## Локальное приложение Bitrix24

В Bitrix24 откройте **Приложения → Разработчикам → Локальное приложение** и создайте приложение типа **Сервер**.

Укажите только права:

- `imopenlines`
- `imconnector`
- `im`

Адрес обработчика установки:

```
https://bl.tube-city.ru/api/bitrix/openline/install?token=ЗНАЧЕНИЕ_BITRIX_OPENLINE_CALLBACK_TOKEN
```

Адрес обработчика событий и настроек:

```
https://bl.tube-city.ru/api/bitrix/openline/handler?token=ЗНАЧЕНИЕ_BITRIX_OPENLINE_CALLBACK_TOKEN
```

Сохраните выданные Bitrix24 `client_id` и `client_secret` в Dokploy как `BITRIX_OPENLINE_APP_CLIENT_ID` и `BITRIX_OPENLINE_APP_CLIENT_SECRET`. После установки приложения сервер зарегистрирует канал **«Чат сайта „Близкие люди“»**.

## Открытая линия

1. Откройте **CRM → Клиенты → Контакт-центр**.
2. Выберите созданный канал «Чат сайта „Близкие люди“» и подключите его к новой Открытой линии.
3. В очереди добавьте менеджеров.
4. В настройках времени работы поставьте ежедневно `09:00–20:00`, Владивосток.
5. В CRM-настройках линии не включайте создание сделки. Если Bitrix24 предлагает создать лид/контакт из нового диалога, это отдельная настройка линии; она не создаёт сделку данным сервером.

## Проверка

1. Откройте сайт в обычном окне браузера.
2. Напишите боту пару сообщений и нажмите «Позвать менеджера».
3. В Bitrix24 должен открыться диалог Открытой линии с полной историей.
4. Ответьте из Bitrix24 — сообщение появится в том же чате сайта максимум через 5 секунд.
5. Не отвечайте 10 минут: сайт попросит телефон и отправит его в тот же диалог.

Интеграция использует официальный механизм кастомного коннектора Open Lines. Он требует OAuth-локальное приложение: входящий CRM-вебхук для этого не подходит.
